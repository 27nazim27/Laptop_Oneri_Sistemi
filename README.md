# Laptop_Oneri_Sistemi
Bu proje, kullanıcıların ihtiyaçlarına ve bütçelerine göre en uygun laptop modellerini öneren bir yapay zekâ destekli tavsiye sistemidir. Sistem, belirli özellikleri (işlemci, RAM, depolama, ekran kartı, kullanım amacı vb.) analiz ederek kullanıcıya en uygun cihazları sıralar
